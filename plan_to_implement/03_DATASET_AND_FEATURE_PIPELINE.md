## 2. Feature Schema & Flow Representation

Standard flow records generated by tools like **CICFlowMeter** contain approximately 80 statistical features per bidirectional flow. FlowGuard categorizes these features into three structural groups:

### Group A: Additive / Scalable Extrinsic Features
These features scale roughly proportionally with the packet sampling rate $p$:
- `Total Fwd Packets`, `Total Backward Packets`
- `Total Length of Fwd Packets`, `Total Length of Bwd Packets`
- `Fwd Header Length`, `Bwd Header Length`
- `Subflow Fwd Packets`, `Subflow Fwd Bytes`

**Distortion Behavior:** Under sampling rate $p$, the observed value is severely deflated ($\tilde{X} \approx p \cdot X$). Naive models see attack volumes appearing as harmless background trickles.

### Group B: Non-Linear Temporal & Inter-Arrival Time (IAT) Features
These features exhibit complex non-linear distortion under packet decimation:
- `Flow Duration`
- `Flow IAT Mean`, `Flow IAT Std`, `Flow IAT Max`, `Flow IAT Min`
- `Fwd IAT Mean`, `Fwd IAT Std`, `Bwd IAT Mean`, `Bwd IAT Std`
- `Active Mean`, `Active Std`, `Idle Mean`, `Idle Std`

**Distortion Behavior:** Sampling drops intermediate packets, causing observed inter-arrival times to appear inflated while variance increases according to geometric random sums.

### Group C: Intrinsic / Shape Features & Flag Ratios
- `Fwd Packet Length Max`, `Fwd Packet Length Min`, `Fwd Packet Length Mean`, `Fwd Packet Length Std`
- `Flow Bytes/s`, `Flow Packets/s`
- `FIN Flag Count`, `SYN Flag Count`, `RST Flag Count`, `PSH Flag Count`, `ACK Flag Count`, `URG Flag Count`
- `Down/Up Ratio`, `Average Packet Size`

**Distortion Behavior:** Rare flags (e.g., SYN packets during stealth port scans) can be completely missed, altering TCP handshake symmetry.

## 3. Data Preprocessing & Cleaning Rules

The raw CSVs of CIC-IDS2017 / 2018 require rigorous hygiene before any modeling:

```python
# Cleaning Checklist
1. Strip leading/trailing whitespaces from column headers.
2. Remove socket identifier features to avoid shortcut learning:
   DROP: ['Flow ID', 'Source IP', 'Source Port', 'Destination IP', 'Destination Port', 'Timestamp']
3. Replace 'Infinity' and '-Infinity' with NaN, then drop or impute.
4. Remove zero-variance (constant) columns (e.g., 'Bwd PSH Flags', 'Fwd URG Flags').
5. Remove negative duration or negative IAT anomalies caused by clock desynchronization.
6. Binary Label Mapping:
   y = 0 if Label == 'BENIGN' else 1 (ATTACK)
7. Save cleaned data to Apache Parquet format (snappy compression) for 10x faster I/O.
```

## 4. Stratified Data Splitting Protocol

To prevent data leakage and ensure realistic validation:

```
Full Clean Dataset (100%)
 ├── Training Set (65%)
 │     └── Used EXCLUSIVELY to train base intrusion detection models on complete flows
 │
 ├── Calibration Set (15%)
 │     └── Used to tune SAFE-3WD risk thresholds (tau_safe, tau_attack, sigma_thresh)
 │     └── Evaluated on sampled traffic to calibrate cost-sensitive risk boundaries
 │
 └── Test Set (20%)
       └── Held-out pristine flows
       └── Subjected to synthetic sampling degradation suites across multiple p rates
       └── Used for the final benchmark against all 4 baseline approaches
```
